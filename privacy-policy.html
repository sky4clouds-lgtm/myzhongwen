게시자 문남수(이하 “개발자”)는 중국어 학습 앱 “我的中文 나의중국어”(이하 “앱”)에서 처리하는 정보와 그 이용 목적, 보관·삭제 방법, 이용자의 선택권을 다음과 같이 안내합니다. 이 방침은 Android 앱과 이 개인정보처리방침 웹페이지에 적용됩니다.

주요 내용
  • 회원가입 없이 이용하며, 카드·학습 기록·설정은 기기에 저장합니다.
  • 개발자는 학습 내용을 개발자 서버로 자동 업로드하지 않습니다.
  • 광고 제공을 위해 Google AdMob 및 동의 관리 SDK를 사용합니다.
  • 듣기·검색·번역·파일 저장을 이용하면 해당 기능의 제공자에게 필요한 정보가 전달될 수 있습니다.

1. 기기에서 처리하는 정보

앱은 문장 등록·학습·복습·통계 제공을 위해 다음 정보를 기기의 앱 전용 저장 영역에서 처리합니다.

앱의 기기 내 처리 정보와 목적
정보이용 목적
중국어 문장·단어, 병음, 한국어 뜻, 설명, 카테고리카드 등록·조회·수정, 병음 생성, 분류와 학습

학습 목표, 타이머, 앞면 언어, 자동듣기, 복습 간격 등 설정이용자가 선택한 학습 방식 적용

병음 자동 생성은 기기에서 수행합니다. 이름·전화번호·이메일·계정 정보를 앱 회원가입 항목으로 입력받지 않으며, 개발자가 운영하는 카드 동기화 서버는 없습니다. 이용자가 카드에 개인 정보를 직접 입력하면 해당 내용도 카드 데이터의 일부로 저장됩니다.

클립보드는 이용자가 붙여넣기 기능을 사용하는 경우 등 앱의 텍스트 작업에 사용합니다. 다른 앱에서 복사한 내용을 백그라운드에서 상시 감시하여 수집하지 않습니다.

2. 광고 및 동의 관리

앱에는 Google AdMob 배너 광고가 포함됩니다. Google Mobile Ads SDK는 광고 제공·측정·분석과 부정행위 방지를 위해 다음 정보를 자동으로 수집·공유할 수 있습니다.

  • IP 주소 및 이를 통해 추정할 수 있는 대략적인 위치
  • 앱 실행, 탭, 동영상 조회 등 제품 상호작용 정보
  • 앱·SDK 실행 시간, 비정상 종료율, 에너지 사용량 등 진단 정보
  • Android 광고 ID, 앱 세트 ID 및 해당하는 경우 기기에 로그인한 계정과 관련된 식별자

실제 처리는 기기·광고 설정·동의 상태와 제공되는 광고 기능에 따라 달라질 수 있습니다. 앱이 로그인을 요구하지 않더라도 광고 SDK를 통한 정보 처리는 이루어질 수 있습니다. 개발자는 카드 원문·병음·뜻·설명·카테고리·학습 기록을 광고 키워드나 맞춤 타기팅 정보로 전달하지 않습니다.

앱은 Google 사용자 메시지 플랫폼(UMP)을 이용해 동의 상태를 확인하고, 필요한 경우 동의 양식을 표시합니다. 광고 요청이 가능하다고 SDK가 판정한 경우에만 광고를 요청합니다. 개인정보 옵션이 필요한 상태이면 앱 설정의 “광고 개인정보 설정”에서 선택을 변경할 수 있습니다. 이 항목의 표시 여부는 지역과 SDK 판정에 따라 다릅니다.

광고 ID의 재설정·삭제 등은 기기의 Android 개인정보 보호 또는 광고 설정에서 관리할 수 있습니다. 맞춤 광고 제한이나 광고 ID 삭제만으로 모든 광고 표시와 모든 정보 처리가 중단되는 것은 아닙니다.

자세한 내용은 Google Mobile Ads 데이터 처리 안내, Google 개인정보처리방침, Google 서비스를 사용하는 앱에서의 정보 이용 안내를 확인할 수 있습니다.

3. 외부 기능과 정보 전달

중국어 듣기

수동 듣기 또는 이용자가 켠 자동듣기를 실행하면 발음할 중국어 텍스트를 기기에 설정된 TTS(텍스트 음성 변환) 엔진에 전달합니다. 엔진·설치된 음성·기기 설정에 따라 기기에서 처리되거나 해당 엔진 제공자의 서버에서 처리될 수 있습니다. 처리 방식과 보관 기준은 선택한 TTS 제공자의 방침을 확인해 주세요.

외부 검색과 번역

텍스트를 선택해 검색·번역 기능을 실행하면 선택한 텍스트를 외부 검색 앱·브라우저·번역 앱으로 전달합니다. 검색 앱을 실행할 수 없을 때는 Google 검색 웹페이지를 열 수 있습니다. 전달 이후의 처리는 해당 서비스의 방침을 따릅니다. 번역 결과로 카드 내용을 자동 변경하지 않습니다.

TXT 파일 가져오기와 내보내기

이용자가 선택한 파일을 읽거나 선택한 저장 위치에 카드 내용을 기록합니다. 클라우드 문서 제공자나 동기화 폴더를 선택하면 해당 제공자가 파일을 처리할 수 있습니다. 내보낸 파일에는 카드 내용만 포함되며 학습 상태·기록·설정은 포함하지 않습니다. 앱이 저장한 외부 파일은 앱 데이터 삭제나 앱 제거만으로 삭제되지 않습니다.

이메일 문의

이용자가 문의 이메일을 보내면 회신 주소, 문의 내용 및 이용자가 첨부한 자료를 문의 확인·답변·문제 해결 목적으로 처리합니다. 문의에 필요하지 않은 민감한 정보나 개인 학습 자료는 보내지 않아도 됩니다.

4. 보관과 삭제

  • 카드·학습 기록·설정: 기기의 앱 데이터에 보관합니다. 앱 삭제 또는 Android 설정에서 이 앱의 저장공간·데이터 삭제를 실행하면 해당 앱 전용 데이터가 삭제됩니다.
  • 카드 삭제: 현재 목록과 신규 학습 대상 등에서 제외하는 방식입니다. 과거 채점·세션 결과·통계를 보존하므로 당시 카드 내용과 삭제 표시가 앱 데이터에 남습니다.
  • 학습 상태 초기화: 현재 암기 상태와 복습 예정 등을 초기화하며 카드 내용과 과거 기록 전체를 삭제하는 기능은 아닙니다.
  • 미확정 TXT 검토: 앱 메모리에서만 유지합니다. 검토 흐름을 벗어나거나 취소하면 정리하며, 앱 재시작 후 자동 복원하지 않습니다.
  • 내보낸 파일: 이용자가 선택한 저장 위치에 남으며 해당 파일·클라우드 서비스에서 직접 삭제해야 합니다.
  • 광고·동의 정보: Google이 처리하는 정보의 보관·삭제는 해당 서비스의 방침과 설정을 따릅니다. 앱 데이터 삭제가 Google의 보유 정보까지 일괄 삭제하는 것은 아닙니다.
  • 문의 정보: 보유기간 3년. "전자상거래 등에서의 소비자보호에 관한 법률 시행령" 소비자 불만에 관한 기록 보관에 따릅니다.

개발자는 기기에 저장된 카드와 기록을 원격으로 조회하거나 삭제할 수 없습니다. 앱은 Android 자동 백업을 사용하지 않도록 설정되어 있습니다. 이용자가 별도로 복사·내보내기한 데이터는 해당 사본을 직접 관리해야 합니다.

5. 외부 제공자와 국외 처리

광고 및 동의 관리에는 Google의 서비스를 사용합니다. 이용자가 선택한 외부 검색·번역·TTS·파일 저장 서비스는 각 제공자가 처리합니다. 개발자는 학습 기록을 판매하거나 광고 타기팅 자료로 제공하지 않습니다.

Google은 전 세계 서버를 운영하며 이용자가 거주하는 국가 외부에서 정보가 처리될 수 있다고 안내합니다. 외부 앱·TTS·클라우드 저장소의 국외 처리 여부는 이용자가 선택한 서비스에 따라 달라집니다.

6. 이용자의 권리와 선택

이용자는 앱에서 카드와 설정을 확인·수정하고, 카드 삭제나 학습 상태 초기화를 실행할 수 있습니다. 과거 기록을 포함한 기기 내 앱 데이터를 모두 지우려면 Android 설정에서 이 앱의 데이터 삭제 또는 앱 제거를 이용할 수 있습니다. 내보낸 파일은 별도로 삭제해 주세요.

이용자는 적용 법령에 따라 개인정보의 열람, 정정·삭제, 처리정지 또는 동의 철회 등을 문의할 수 있습니다. 개발자가 보유한 문의 정보와 관련된 요청은 아래 문의 이메일로 보내 주세요. 기기에만 저장된 자료는 개발자가 원격 처리할 수 없어 기기에서 실행하는 방법을 안내할 수 있습니다.

광고 관련 선택은 제공되는 동의 양식·광고 개인정보 설정·Android 광고 설정에서 관리할 수 있습니다. 외부 검색·번역·TTS 기능을 사용하지 않거나 자동듣기를 끄면 해당 기능을 통한 텍스트 전달을 피할 수 있습니다. 외부 서비스가 보유한 정보에 대한 요청은 해당 서비스의 권리 행사 절차도 확인해 주세요.

7. 정보 보호 조치

카드·학습 기록·설정은 Android의 앱 전용 저장 영역에 보관하고 운영체제의 접근 제한을 이용합니다. 앱은 파일 가져오기·내보내기에 이용자가 선택한 파일과 저장 위치를 사용합니다. 광고 SDK가 수집하는 사용자 데이터는 Google의 안내에 따라 전송 중 TLS로 암호화됩니다.

이용자는 기기 잠금과 운영체제 업데이트를 유지하고 내보낸 TXT 파일과 문의 첨부자료의 접근 권한을 관리해 주세요.

8. 이용 연령

앱은 만 13세 이상 일반 사용자를 대상으로 하며 아동 대상 서비스로 제작되지 않았습니다. 회원가입이나 생년월일 입력 기능은 없습니다. 보호자는 자녀의 앱 이용 또는 개인정보 처리에 관해 아래 문의처로 연락할 수 있습니다. 동의가 필요한 아동의 정보 처리에 관한 요청은 적용 법령과 실제 처리 상황에 따라 확인합니다.

9. 개인정보처리방침 웹페이지

이 페이지를 GitHub Pages에 게시한 경우 페이지 방문자의 IP 주소가 서비스 보안 목적으로 GitHub에 기록·보관됩니다. 이는 앱의 카드·학습 기록 저장과 별개입니다. 이 페이지에는 개발자가 추가한 광고, 방문 분석 도구, 문의 입력 양식 또는 외부 글꼴이 없습니다.

자세한 내용은 GitHub Pages 데이터 처리 안내와 GitHub 개인정보처리방침을 확인해 주세요. 외부 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다.
